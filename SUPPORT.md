# Support

The Playbook supports questions and defects about its public documentation, catalog, static site, and machine-readable outputs.

## Where to ask

- Use the [Playbook issue tracker](https://github.com/Agentic-Engineering-Agency/playbook/issues) for incorrect documentation, broken links, locale gaps, accessibility problems, and site behavior.
- Use the project repository linked from the [public catalog](https://labs.agenticengineering.agency/docs/projects) for product-specific installation, runtime, release, or implementation support.
- Use the [Agentic Engineering website](https://agenticengineering.agency) for services and private commercial conversations.
- Use the private process in [SECURITY.md](SECURITY.md) for vulnerabilities.

## Public issue safety

Provide the affected public URL, locale, expected behavior, actual behavior, and canonical evidence when relevant. Do not include credentials, customer information, private repository links, internal project status, or other confidential material.

The Playbook is a public documentation surface, not a service-status dashboard or a support channel for every cataloged project.
