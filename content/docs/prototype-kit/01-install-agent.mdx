Gemini CLI is an open-source AI coding agent from Google. It runs in your terminal and can read project files, write code, and execute commands on your behalf.

<Callout type="warn">
**Access changed on June 18, 2026.** Gemini CLI no longer serves individual free, Google AI Pro, or Google AI Ultra accounts. Continue only if you have an eligible organization or Google Cloud entitlement, or a paid Gemini API key. See the [official transition notice](https://github.com/google-gemini/gemini-cli/discussions/27274) before installing. Prototype Kit also supports Claude Code through its [verified plugin path](/docs/prototype-kit/02-install-mcps#install-via-claude-code-plugin); Claude access has its own subscription or API requirements.
</Callout>

## Install Node.js first

Gemini CLI requires Node.js 18 or later. Check your version:

```bash
# macOS / Linux
node --version
```

```powershell
# Windows PowerShell
node --version
```

If `node` is not found or the version is below 18, download and install Node.js from [https://nodejs.org](https://nodejs.org) (choose the LTS version).

## Install Gemini CLI

```bash
# macOS / Linux
npm install -g @google/gemini-cli
```

```powershell
# Windows PowerShell
npm install -g @google/gemini-cli
```

## Verify the installation

```bash
# macOS / Linux
gemini --version
```

```powershell
# Windows PowerShell
gemini --version
```

Expected output: a version string such as `0.x.x`.

## Configure supported access

Launch `gemini` for the first time:

```bash
# macOS / Linux
gemini
```

```powershell
# Windows PowerShell
gemini
```

Follow the prompt using the organization or Google Cloud account that provides your Gemini CLI entitlement. Once authenticated, the terminal shows the interactive prompt. Type `/quit` to exit and return to your shell.

<Callout type="info">
**API-key or headless access:** export a paid `GEMINI_API_KEY` before launching `gemini`. Review the [current Gemini API pricing and rate limits](https://ai.google.dev/gemini-api/docs/rate-limits) rather than assuming free access.
</Callout>

## Claude Code alternative

If you do not have a supported Gemini CLI entitlement, set up Claude Code instead and follow the same five steps. Install it with the [official setup guide](https://code.claude.com/docs/en/setup), confirm it launches, and then use the Claude Code section of Step 2 to add the plugin:

```bash
# macOS / Linux
claude --version
```

```powershell
# Windows PowerShell
claude --version
```

The two plugin commands run inside an interactive `claude` session and match the verified paths on the [Kits page](/docs/kits#prototype-kit):

```
/plugin marketplace add Agentic-Engineering-Agency/prototype-kit
/plugin install prototype-kit@prototype-kit
```

Step 2 covers this path in full at [Install via Claude Code plugin](/docs/prototype-kit/02-install-mcps#install-via-claude-code-plugin). Do not skip it: Steps 4 and 5 assume the plugin is already installed.
