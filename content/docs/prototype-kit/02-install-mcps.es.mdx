---
title: "Paso 2: Instalar prototype-kit"
description: Agrega prototype-kit a Gemini CLI o Claude Code y verifica que esté registrado.
---

prototype-kit lo mantiene Agentic Engineering Agency y se distribuye como extensión de Gemini CLI y como plugin de Claude Code. Cualquiera de las dos rutas agrega el comando del prototipo al agente y lo configura para crear proyectos con React + Vite + shadcn/ui. Sigue la sección que corresponda al agente que instalaste en el Paso 1.

## Instalar mediante extensiones de Gemini CLI

```bash
# macOS / Linux
gemini extensions install --consent https://github.com/Agentic-Engineering-Agency/prototype-kit
```

```powershell
# Windows PowerShell
gemini extensions install --consent https://github.com/Agentic-Engineering-Agency/prototype-kit
```

La bandera `--consent` salta el prompt interactivo de confirmación. Sin ella, la instalación puede quedar en silencio cuando stdin está canalizado (por ejemplo, dentro de un script). El agente descargará e instalará la extensión automáticamente. Deberías ver:

```
Extension 'prototype-kit' installed successfully.
```

## Verificar que la extensión está registrada

```bash
# macOS / Linux
gemini extensions list
```

```powershell
# Windows PowerShell
gemini extensions list
```

La salida esperada incluye:

```
prototype-kit  v0.x.x  Agentic Engineering Agency
```

## Confirmar la instalación en disco

Ejecuta `gemini extensions list` en tu terminal como se muestra arriba. Si ya estás dentro de una sesión interactiva de Gemini CLI, usa `/extensions list`. Para verificar directamente el archivo instalado:

```bash
# macOS / Linux
ls ~/.gemini/extensions/prototype-kit/gemini-extension.json
```

```powershell
# Windows PowerShell
Get-Item $HOME\.gemini\extensions\prototype-kit\gemini-extension.json
```

Si el archivo aparece, la instalación funcionó. Si dice "No such file", vuelve a correr el comando de install con la bandera `--consent`.

## Instalar mediante el plugin de Claude Code

Si sigues la ruta de Claude Code en lugar de Gemini CLI, primero instala Claude Code con la [guía oficial de instalación](https://code.claude.com/docs/en/setup) y luego ábrelo desde tu terminal:

```bash
# macOS / Linux
claude
```

```powershell
# Windows PowerShell
claude
```

Dentro de esa sesión interactiva, ejecuta los dos comandos de plugin verificados que también aparecen en la [página de Kits](/es/docs/kits#prototype-kit):

```
/plugin marketplace add Agentic-Engineering-Agency/prototype-kit
/plugin install prototype-kit@prototype-kit
```

Cuando el plugin queda instalado, el comando con namespace `/prototype-kit:prototype-from-docs` aparece en la lista de comandos `/help` de esa sesión; el Paso 4 usa esa forma para Claude Code. El acceso a Claude Code tiene sus propios requisitos de suscripción o API, y el paquete npm que menciona el README de prototype-kit no es público, así que aquí no se documenta ningún comando `npx`.

## Fallback manual (detrás de un proxy o sin red)

Si el install desde la URL de GitHub falla por tu red (proxy corporativo, portal cautivo, etc.), clona el repo y corre el instalador incluido:

```bash
git clone https://github.com/Agentic-Engineering-Agency/prototype-kit.git
cd prototype-kit
node bin/install.js
```

El instalador detecta las herramientas compatibles Gemini CLI y Claude Code en tu PATH y escribe la configuración correspondiente.
