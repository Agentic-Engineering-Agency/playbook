Gemini CLI es un agente de IA de código abierto de Google. Corre en tu terminal y puede leer los archivos de tu proyecto, escribir código y ejecutar comandos.

<Callout type="warn">
**El acceso cambió el 18 de junio de 2026.** Gemini CLI dejó de atender cuentas individuales gratuitas, Google AI Pro y Google AI Ultra. Continúa solo si tienes acceso elegible mediante una organización o Google Cloud, o una clave de pago de la API de Gemini. Revisa el [aviso oficial de transición](https://github.com/google-gemini/gemini-cli/discussions/27274) antes de instalar. Prototype Kit también admite Claude Code mediante su [ruta verificada de plugin](/es/docs/prototype-kit/02-install-mcps#instalar-mediante-el-plugin-de-claude-code); el acceso a Claude tiene sus propios requisitos de suscripción o API.
</Callout>

## Primero instala Node.js

Gemini CLI requiere Node.js 18 o superior. Verifica tu versión:

```bash
# macOS / Linux
node --version
```

```powershell
# Windows PowerShell
node --version
```

Si `node` no se encuentra o la versión es menor a 18, descarga e instala Node.js desde [https://nodejs.org](https://nodejs.org) (elige la versión LTS).

## Instalar Gemini CLI

```bash
# macOS / Linux
npm install -g @google/gemini-cli
```

```powershell
# Windows PowerShell
npm install -g @google/gemini-cli
```

## Verificar la instalación

```bash
# macOS / Linux
gemini --version
```

```powershell
# Windows PowerShell
gemini --version
```

Resultado esperado: una cadena de versión como `0.x.x`.

## Configurar un acceso compatible

Ejecuta `gemini` por primera vez:

```bash
# macOS / Linux
gemini
```

```powershell
# Windows PowerShell
gemini
```

Sigue el flujo con la cuenta de organización o Google Cloud que te da acceso a Gemini CLI. Al terminar verás el prompt interactivo. Escribe `/quit` para regresar a tu terminal.

<Callout type="info">
**Acceso por clave o en una máquina sin navegador:** exporta un `GEMINI_API_KEY` de pago antes de lanzar `gemini`. Revisa los [precios y límites vigentes de la API de Gemini](https://ai.google.dev/gemini-api/docs/rate-limits) en lugar de asumir acceso gratuito.
</Callout>
