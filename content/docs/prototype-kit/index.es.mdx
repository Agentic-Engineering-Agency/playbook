Bienvenido a **prototype-kit** — una guía paso a paso para equipos que quieren construir un prototipo con React + shadcn/ui mediante un agente de IA. Las rutas públicas de instalación documentadas aquí cubren Gemini CLI y Claude Code.

<Callout type="info">
**Agentes de IA:** Descarga [`/llms-full.txt`](/llms-full.txt) para obtener la versión completa en formato legible por máquinas. Incluye las cinco páginas concatenadas con títulos y URLs como separadores.
</Callout>

## Qué vas a construir

Un prototipo web funcional con pantallas, navegación y componentes con estilo generado a partir de tus documentos de producto. El tiempo y la cantidad de código manual dependen del proyecto y del resultado del agente.

## Los cinco pasos

<Cards>
  <Card title="1. Instalar un agente compatible" href="/es/docs/prototype-kit/01-install-agent">
    Confirma acceso vigente a Gemini CLI mediante una organización, Cloud o clave de pago, o usa la ruta verificada del plugin de Claude Code.
  </Card>
  <Card title="2. Instalar prototype-kit" href="/es/docs/prototype-kit/02-install-mcps">
    Agrega la extensión de Gemini CLI o el plugin de Claude Code para que el agente sepa cómo crear proyectos React.
  </Card>
  <Card title="3. Preparar tus documentos" href="/es/docs/prototype-kit/03-prepare-docs">
    Escribe tres documentos cortos que le indiquen al agente qué construir.
  </Card>
  <Card title="4. Ejecutar el prompt" href="/es/docs/prototype-kit/04-run-prompt">
    Abre el agente, ejecuta un comando y responde sus preguntas de aclaración.
  </Card>
  <Card title="5. Abrir el prototipo" href="/es/docs/prototype-kit/05-open-prototype">
    Inicia el servidor de desarrollo y ve tu prototipo en el navegador.
  </Card>
</Cards>
