Welcome to **prototype-kit** — a step-by-step guide for teams that want to build a React + shadcn/ui prototype with an AI coding agent. The public installation paths documented here cover Gemini CLI and Claude Code.

<Callout type="info">
**AI agents:** Fetch [`/llms-full.txt`](/llms-full.txt) for the complete machine-readable version of this guide. It includes all five pages concatenated with titles and URLs as separators.
</Callout>

## What you will build

A working web prototype with screens, navigation, and styled components generated from your product documents. Completion time and the amount of manual coding depend on the project and agent output.

## The five steps

<Cards>
  <Card title="1. Install a supported agent" href="/docs/prototype-kit/01-install-agent">
    Confirm a current Gemini CLI organization, Cloud, or paid-key entitlement, or use the verified Claude Code plugin path.
  </Card>
  <Card title="2. Install prototype-kit" href="/docs/prototype-kit/02-install-mcps">
    Add the prototype-kit extension so the agent knows how to scaffold React projects.
  </Card>
  <Card title="3. Prepare your docs" href="/docs/prototype-kit/03-prepare-docs">
    Write three short documents that tell the agent what to build.
  </Card>
  <Card title="4. Run the prompt" href="/docs/prototype-kit/04-run-prompt">
    Open the agent, run one command, and answer its clarifying questions.
  </Card>
  <Card title="5. Open the prototype" href="/docs/prototype-kit/05-open-prototype">
    Start the dev server and see your prototype in the browser.
  </Card>
</Cards>
