# Public projects

This catalog includes organization-owned, non-archived public repositories with enough canonical documentation or distribution evidence to explain and use responsibly. It is a public discovery surface, not a live portfolio or internal status tracker.

<Callout type="info">
**Ownership:** every entry links to a non-fork repository owned by `Agentic-Engineering-Agency`. **Review date:** July 29, 2026. Re-check the source before relying on current release or compatibility details.

## Inclusion boundary

Public visibility alone is not enough. Archived repositories, upstream forks, landing-page implementations, internal knowledge workspaces, empty marketplaces, and public previews with unresolved ownership, licensing, or internal-content boundaries are omitted until they have a clear public release surface.

[Read the evidence rules](/docs/proof) or [inspect the complete public organization](https://github.com/Agentic-Engineering-Agency).
