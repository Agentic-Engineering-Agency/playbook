The Agentic Engineering Playbook is a public, bilingual documentation and proof-distribution surface. It exists to help readers inspect and use the open methods and kits that Agentic Engineering intentionally publishes.

## What belongs here

- reviewed guides for public methods and kits
- install paths verified against the linked source repository or package registry
- machine-readable documentation through `/llms.txt` and `/llms-full.txt`
- public proof paths only after their sources and claims have been reviewed

## What does not belong here

- internal operating dashboards or live project status
- customer workspaces, private data, credentials, or internal runbooks
- unverified portfolio, performance, ownership, or production claims
- copied product documentation without a clear source and review path

The linked product repositories remain the source for releases and implementation details. The [Agentic Engineering website](https://agenticengineering.agency) owns the public services and contact journey.

## Publication rule

If a command, claim, or proof path cannot be verified, it is omitted or labeled before publication. Documentation is reviewed in both English and Spanish, and the repository verification checks enforce locale-pair coverage for public MDX pages.
