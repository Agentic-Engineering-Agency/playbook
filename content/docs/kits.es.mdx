# Kits

Los kits convierten métodos públicos en skills, plantillas y flujos reutilizables para agentes. Los comandos aparecen aquí solo cuando el repositorio fuente y la distribución pública coinciden.

<Cards>
  <Card title="Agentic PM Kit" href="/es/docs/pm-kit">
    Agent Skills de gestión de proyectos para redactar artefactos con forma PMBOK y Scrum en Claude Code y Gemini CLI.
  </Card>
  <Card title="Prototype Kit" href="/es/docs/prototype-kit">
    Un plugin y extensión distribuidos desde fuente para convertir documentos de producto en prototipos con React y shadcn/ui.
  </Card>
  <Card title="SpecSafe CLI" href="https://github.com/Agentic-Engineering-Agency/specsafe">
    Un CLI público para instalar el flujo de planeación y entrega guiada por especificaciones de SpecSafe en herramientas compatibles.
  </Card>
</Cards>

## Rutas de distribución verificadas

### Agentic PM Kit

El paquete `agentic-pm-kit` es público en npm y el siguiente comando coincide con su README canónico.

```bash
npx agentic-pm-kit install
```

### Prototype Kit

Prototype Kit se distribuye actualmente mediante manifests de Claude Code y Gemini CLI respaldados por el código fuente. Su README también menciona un paquete npm que no es público, por lo que ese comando se omite intencionalmente.

```bash
# Claude Code
/plugin marketplace add Agentic-Engineering-Agency/prototype-kit
/plugin install prototype-kit@prototype-kit

# Gemini CLI
gemini extensions install --consent https://github.com/Agentic-Engineering-Agency/prototype-kit
```

### SpecSafe

El paquete `@specsafe/cli` es público en npm y el comando coincide con el repositorio canónico.

```bash
npm install -g @specsafe/cli
```

<Callout type="warn">
Vuelve a revisar la fuente enlazada antes de instalar. El catálogo es una publicación revisada, no un registro de paquetes en vivo.
</Callout>
