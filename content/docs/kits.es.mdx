## Rutas de distribución verificadas

### Agentic PM Kit

El [paquete `agentic-pm-kit` es público en npm](https://www.npmjs.com/package/agentic-pm-kit), y el siguiente comando coincide con la [sección Install](https://github.com/Agentic-Engineering-Agency/agentic-pm-kit/blob/master/README.md#install) del repositorio canónico.

```bash
npx agentic-pm-kit install
```

### Prototype Kit

Prototype Kit se distribuye actualmente mediante manifests de Claude Code y Gemini CLI respaldados por el código fuente. Su README también menciona un paquete npm que no es público, por lo que ese comando se omite intencionalmente.

Para Claude Code, abre `claude` en la carpeta de tu proyecto y luego ejecuta estos comandos dentro de su sesión interactiva:

```bash
claude
```

```text
/plugin marketplace add Agentic-Engineering-Agency/prototype-kit
/plugin install prototype-kit@prototype-kit
/reload-plugins
```

Para Gemini CLI, ejecuta la instalación de la extensión desde tu terminal:

```bash
gemini extensions install --consent https://github.com/Agentic-Engineering-Agency/prototype-kit
```

### SpecSafe

El [paquete `@specsafe/cli` es público en npm](https://www.npmjs.com/package/@specsafe/cli), y el comando coincide con la [sección Quick Start](https://github.com/Agentic-Engineering-Agency/specsafe/blob/main/README.md#quick-start) del repositorio canónico.

```bash
npm install -g @specsafe/cli
```
